# Undangan Pernikahan Sigit & Putri

Website undangan statis, responsif untuk ponsel dan desktop. Tidak menggunakan musik.

## Fitur
- Countdown menuju 28 November 2026 pukul 13.00 WIB.
- Foto prewedding dan QR amplop digital.
- Tombol lokasi Google Maps.
- Form RSVP yang membuka WhatsApp `085749267989`.
- Form ucapan yang tersimpan di browser/perangkat yang digunakan.

> Catatan: ucapan tidak otomatis tersinkron ke perangkat tamu lain. Untuk penyimpanan bersama, perlu menghubungkan database atau layanan formulir.

## Cara upload ke GitHub Pages
1. Ekstrak ZIP ini.
2. Masuk ke GitHub dan buat repository baru, misalnya `undangan-sigit-putri`.
3. Upload semua isi folder ini ke root repository (file `index.html` harus berada di root, bukan di dalam folder tambahan).
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
7. Tunggu proses selesai. GitHub akan menampilkan URL website di menu **Settings → Pages**.

## Uji sebelum dibagikan
- Pastikan tautan Google Maps terbuka dengan benar.
- Pindai QR amplop digital dan verifikasi detail penerima sebelum transaksi.
- Uji RSVP dari ponsel untuk memastikan WhatsApp terbuka ke nomor yang benar.
